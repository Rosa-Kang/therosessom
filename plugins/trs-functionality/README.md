##  TRS Functionality Plugin
This plugin provides core functionality for the website, designed to be theme-independent and easily scalable.

## Folder Structure
```
└── trs-functionality/
    ├── src/
    │   ├── Core/
    │   │   └── General.php
    │   ├── PostTypes/
    │   │   ├── BusinessInfoPostType.php
    │   │   ├── PortfolioPostType.php
    │   │   └── TestimonialPostType.php
    │   └── Taxonomies/
    │       ├── PortfolioCategory.php
    │       └── TestimonialCategory.php
    ├── vendor/                 # Generated by Composer
    ├── composer.json           # New: For autoloading
    ├── trs-functionality.php   # Renamed & updated main plugin file
    └── README.md               # Updated
```

## Installation

1.  Place the `trs-functionality` folder in your WordPress `wp-content/plugins/` directory.
2.  Navigate to the `trs-functionality` directory in your terminal.
3.  **Ensure you have PHP and Composer installed.** If not, follow the instructions below to install them via Homebrew.
4.  Run `composer install` to download dependencies and set up autoloading.
5.  Activate the "TRS Functionality" plugin from your WordPress admin dashboard.

## Composer Usage

This plugin utilizes Composer for managing dependencies and autoloading classes.
After placing the plugin in your `plugins` directory, you **must** run `composer install` from within the `trs-functionality` folder. This will create a `vendor/autoload.php` file, which the plugin relies on to function correctly.

## Custom Post Types

* **Testimonials:** For client testimonials.
* **Portfolio:** For showcasing project portfolios, categorized by Video and Photography.
* **Business Info:** For centralizing business details (logo, social profiles, etc.).

## Custom Taxonomies

* **Testimonial Categories:** Categories for testimonials.
* **Portfolio Categories:** Categories for portfolio items (e.g., Video, Photography).
